# Metafacture Flux Extension

This extension provides language support for Metafacture Flux in the form of autocompletion. More capabilities will follow.
The extension connects to a language server using websockets (`wss:metafacure.org/ls`), so you need access to the internet to use this extension.
For more information, visit https://metafacture.org and https://github.com/metafacture/metafacture-lsp.
